# My Cat V0.6 Playtest

这是一版面向早期测试用户的 Windows 试玩包，重点新增轻量互动小游戏。

## 本版更新

- 新增“和它玩一会儿”：毛线铃铛玩具会出现在鼠标附近，小猫会追逐它。
- 小猫抓到玩具后会播放抱住毛线铃铛的动作。
- 玩耍中右键可以提前停止，小猫会表现出还想玩的失落感。
- 新增 `play_ready`、`play_chase`、`play_catch`、`play_miss` 四组动作资产。
- 试玩包包含 `toys\yarn_bell.png` 玩具资产，并在启动和打包时检查缺失。

## 已知限制

- 暂不做分数、排行榜、多种玩具或多屏追逐。
- 玩具不会真正替换系统鼠标指针，只是一个不拦截点击的透明浮窗。
- 第一版追逐只使用单方向动作，由程序朝向处理。

## 反馈重点

请特别观察：

- 追逐是否像小猫真的在和你互动。
- 抱住玩具动作是否足够可爱、有记忆点。
- 右键停止是否顺手，失落动作是否可爱但不过度悲伤。
